# FDETechnicalScreen

## How to run the program:

Open a terminal or command prompt.

```bash
python fde.py
```

Enter the input as specified.

### **Input:**

1. An integer `N` – the number of packages to process.
2. For each package, a line with **four integers** separated by spaces:

   ```
   width height length mass
   ```

#### Example input:

```
2
100 50 30 10
200 50 40 25
```

This represents 2 packages:
- First package: 100 cm × 50 cm × 30 cm, 10 kg
- Second package: 200 cm × 50 cm × 40 cm, 25 kg
